# Angry Aviators

A complete, original slingshot physics game for the browser.

**Play:** https://umzahid.github.io/angry-aviators/

- 12 hand-built levels
- 4 birds with special abilities
- Destructible wood, ice, stone, and chain-reacting TNT
- 3-star scoring and saved progress
- Touch, mouse, and keyboard controls
- Installable PWA with offline play

All artwork is drawn in code. All sound is synthesized at runtime. No
third-party game assets are used. See `LICENSE` and
`assets/THIRD-PARTY-NOTICES.txt`.

This repository contains the static production build deployed with GitHub
Pages.
